AI Enrichment Ollama

Use a local Ollama model to auto-tag saved content with topics, summaries, and categories. These appear in the YAML frontmatter of your Markdown files.

Requires Ollama running locally

Smaller = faster. Larger = better tags.

AI will add these fields to your saved Markdown frontmatter:

---
source: https://example.com/article
saved: 2026-03-03T10:30:00Z
ai_tags: [machine-learning, transformers, nlp]
ai_summary: "Overview of attention mechanisms in modern language models."
ai_category: research
---

---

published: 2026-02-15
ai_tags: [machine-learning, llm, tutorial]

Tips

  • Files save inside your Downloads folder (browser limitation).
  • To save to a custom location, create a symlink:
    ln -s /your/desired/path ~/Downloads/SaveResearch
  • Works on all Chromium browsers: Chrome, Brave, Edge, Arc, Opera.
  • For Firefox, load the folder as a temporary add-on via about:debugging.
  • Install Ollama: brew install ollama then ollama pull qwen3.5:4b
